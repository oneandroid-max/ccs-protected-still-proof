Decoy frame: each frame a disruption, the pair the photo

Two frames alternate. Each carries the photo plus a strong structured pattern, and the second carries the same pattern inverted, so the eye's blend is the clean photo while a single frame is dominated by the pattern. The pattern is built at several sizes so that blurring a screenshot does not wash it away, and it is balanced within every small block so no area changes brightness between frames. Amplitude and block size are adjustable in the link: ?a=110&s=32. The physics sets the ceiling before you test: where the photo is very dark or very bright the pattern has no room, and a recording, which keeps every frame, averages back to the photo.
