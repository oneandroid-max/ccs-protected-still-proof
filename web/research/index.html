Can a web page make a capture come out black without a vendor path?

Each candidate is tried one at a time on a stock browser with no vendor DRM, and the result is one screenshot. A pass is a black capture. None is expected; the point is to close the question with evidence, not opinion. Results are logged in PLAN.md with the device, system, browser and the screenshot's hash.

Why none of these is expected to pass

The browser hands every frame it draws to the device's compositor, and the device's screenshot reads that compositor. Only a surface the device marks as protected is left out, and on the web such surfaces exist only behind the vendor DRM paths that are ruled out. A page can change what it draws (candidate 6 does), where it draws (2, 3, 5) and how the bytes arrive (4); it cannot change what the device does with the frame once drawn.
