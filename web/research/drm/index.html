Route 1: the browser's own protected video path

No install. A short video is encrypted with Common Encryption and the browser's own DRM decrypts it inside the device's protected path, played here by the same player the first proof used. Chrome and Edge on Android use Widevine; Edge on Windows uses PlayReady; Safari uses FairPlay. Where the device grants hardware protection the screen shows the picture while every capture of it is black; where it grants only software decryption the capture shows the video. Read the result first, then tap Play — it tries whatever DRM this browser actually has.
