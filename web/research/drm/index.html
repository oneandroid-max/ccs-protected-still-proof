Route 1: the browser's own protected video path

No install. The photo is a short video encrypted with Common Encryption; the browser's own DRM decrypts it inside the device's protected path (Widevine in Chrome and Edge, PlayReady as a fallback in Edge on Windows). The photo is shown only where the device keeps it out of screenshots. This page asks the browser for hardware protection levels and nothing lower; a browser that can only decrypt in software is never given the key, so the photo is never decrypted there and is held back. It starts on its own when the page opens; the buttons only run it again.
