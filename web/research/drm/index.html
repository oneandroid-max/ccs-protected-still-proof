Route 1: the browser's own protected video path

No install. The photo is a short video encrypted with Common Encryption; the browser's own DRM decrypts it inside the device's protected path (Widevine in Chrome and Edge, PlayReady as a fallback in Edge on Windows). The photo is shown only where screenshots are known to come out black: with hardware protection on any device, and with software protection in Chrome and Edge on Windows and Android, where screenshots were measured black. On other browsers and platforms the photo is held back until each is measured the same way. It starts on its own when the page opens; the buttons only run it again.
